# Terminology

- **NiceGUI** - Python UI framework using Quasar/Vue components, allows building web UIs with Python
- **Quasar** - Vue.js component framework that NiceGUI wraps
- **Pylance** - Python language server providing type information and IntelliSense
- **LSP** - Language Server Protocol, standardized communication for IDE language features
- **Context Kind** - Categorization of current completion context: `props`, `events`, `methods`, `slots`, `classes`, `style`, or `icons`
- **Companion Files** - Related files for a component: `.py` script paired with `.vue` or `.js` template
- **Inject Grammar** - TextMate grammar that extends an existing language (Python) rather than defining a new one
